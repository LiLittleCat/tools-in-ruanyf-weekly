    阮一峰老师科技爱好者周刊汇总¶

    前言¶

    很喜欢阮一峰老师的 科技爱好者周刊，尤其是「工具」和「资源」部分内容，非常有趣且实用。

    但是到目前为止周刊已经太多期，苦于查找困难，特将其汇总于此，方便查阅。

    新版站点（推荐）¶

    在线访问：https://ruanyf-weekly.yl.do

    基于 Fumadocs（Astro）重新搭建的栏目汇总站，代码在 fumadocs 分支：

    • 栏目汇总：话题、科技动态、文章、教程、工具、资源、AI 相关、图片、文摘、言论 —— 每个栏目把所有期数的内容集中在一起，按年份分册浏览
    • 期刊归档：每一期的完整原文，按年份归类
    • 全文搜索：支持中文，覆盖所有期数的正文
    • 每周五自动同步最新一期，由 Cloudflare Pages 构建发布

    最新一期¶

    科技爱好者周刊（第 406 期）：道可，道非，常道¶

    工具¶

    1、Orion

    Kagi 公司推出的浏览器，支持桌面和手机，采用 WebKit 内核，同时支持 Safari、Chrome 和 Firefox 扩展程序，承诺隐私保护、零遥测和广告拦截。

    2、Chirp

    通过声音（喇叭和麦克风），发送和接收数据的一个开源工具。

    3、Bento Slides

    只需要一个 HTML 文件的 PowerPoint 编辑器/播放器。

    4、lazyrsync

    为文件同步工具 rsync 添加的终端界面。（@pobin6 投稿）

    5、Birth

    开源的 macOS 启动项管理工具，把系统里每一个后台项、守护进程和登录项收进同一个窗口，可以一键停用或移除。（@iAmCorey 投稿）

    6、Linux Router

    将 Debian 或 Armbian 设备变成路由器，并提供一个清晰的 Web 控制台。（@Jaksay 投稿）

    7、RepoMirror

    一个 macOS 桌面应用，将 GitHub 仓库或其中的指定目录镜像同步至本地，不必检查几十个 GitHub 项目有没有更新。（@wutongyuonce 投稿）

    8、FluxDown

    开源的多协议下载器，内置 MCP 服务器，可供 Agent 调用。（@zerx-lab 投稿）

    9、米饭云盘

    基于 Telegram Channel 的小文件开源存储系统，适合部署为个人图床 / Markdown 图床。（@AndySkaura 投稿）

    10、StaticShield

    为网页加上密码保护的 JS 库，加密后只有输入密码才能访问。（@wangshengithub 投稿）

    资源¶

    1、How to Draw

    这个网站有各种小动物的分步绘图指导，适合小朋友使用。（@Etshop-AI 投稿）

    2、网页滚动的动画效果（英文）

    这个网站收集各种网页滚动的动画效果，使用 Web Animations API (WAAPI) 和 CSS Animations API 实现。

    3、学习下围棋

    在线互动围棋教程，从零开始分课讲解。
