    阮一峰老师科技爱好者周刊汇总¶

    前言¶

    很喜欢阮一峰老师的 科技爱好者周刊，尤其是「工具」和「资源」部分内容，非常有趣且实用。

    但是到目前为止周刊已经太多期，苦于查找困难，特将其汇总于此，方便查阅。

    新版站点（推荐）¶

    在线访问：https://ruanyf-weekly.yl.do

    基于 Fumadocs（Astro）重新搭建的栏目汇总站，代码在 fumadocs 分支：

    • 栏目汇总：话题、科技动态、文章、教程、工具、资源、AI 相关、图片、文摘、言论 —— 每个栏目把所有期数的内容集中在一起，按年份分册浏览
    • 期刊归档：每一期的完整原文，按年份归类
    • 全文搜索：支持中文，覆盖所有期数的正文
    • 每周五自动同步最新一期，由 Cloudflare Pages 构建发布

    最新一期¶

    科技爱好者周刊（第 416 期）：编程已经面目全非¶

    工具¶

    1、sslx

    一个检测、查看 HTTPS 证书信息的命令行工具。

    2、Mac.apk

    这个应用可以让 Mac 运行安卓软件，不是虚拟机，也不是模拟器，原理是模拟安卓的系统 API。

    3、siltop

    一个 macOS 命令行工具，在终端显示各种实时的系统信息：CPU、GPU、内存、电力、温度、存储、网络等。

    4、Little Snitch Mini

    一个 macOS 软件，显示正在运行的所有应用的互联网连接，并可以阻断指定的单个连接。

    5、Pines

    一个基于 Tailwind 的 UI 组件库。

    6、silkpulse

    前端的远程页面调试工具。在页面插入一个脚本，就可以远程打开该网页的控制台，查看各种信息，接收实时报错，适合调试手机端页面。（@2234839 投稿）

    7、TaskbarLyrics

    Windows 任务栏实时显示歌词，支持国内主要音乐服务。（@ANYNC 投稿）

    8、Archify

    一个 Skill 项目，将一段话、一个计划、一个代码仓库变成互动式网页流程图。（@zhengxin-wang 投稿）

    9、html-to-video

    一个把 HTML 网页动画逐帧渲染成 MP4 视频的命令行工具。（@wx4766 投稿）

    10、Parcel

    基于 Cloudflare Worker 环境的临时文件分享应用，上传文件后生成加密的分享链接，到期自动清理。（@hyphy-void 投稿）

    11、douban-cli

    豆瓣的非官方命令行客户端，可以用来获取电影、剧集、图书的数据。（@Marvae 投稿）

    12、wol

    一个命令行工具，可以通过命令行或 Web 界面，唤醒当前局域网里面某台正在休眠的计算机。

    资源¶

    1、大鹏书法

    查看某个字的各种书法。（@gengdapeng-beep 投稿）

    2、学习 Vim（Learn Vim the Smart Way）

    一个开源的 Vim 编辑器教程，这是英文版。另有中文版。

    3、编译器和语言设计导论（Introduction to Compilers and Language Design）

    一本免费的英语教材，面向初学者，介绍编译器的概念，以及如何写一个 C 语言的编译器。
