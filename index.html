    阮一峰老师科技爱好者周刊汇总¶

    前言¶

    很喜欢阮一峰老师的 科技爱好者周刊，尤其是「工具」和「资源」部分内容，非常有趣且实用。

    但是到目前为止周刊已经太多期，苦于查找困难，特将其汇总于此，方便查阅。

    新版站点（推荐）¶

    在线访问：https://ruanyf-weekly.yl.do

    基于 Fumadocs（Astro）重新搭建的栏目汇总站，代码在 fumadocs 分支：

    • 栏目汇总：话题、科技动态、文章、教程、工具、资源、AI 相关、图片、文摘、言论 —— 每个栏目把所有期数的内容集中在一起，按年份分册浏览
    • 期刊归档：每一期的完整原文，按年份归类
    • 全文搜索：支持中文，覆盖所有期数的正文
    • 每周五自动同步最新一期，由 Cloudflare Pages 构建发布

    最新一期¶

    科技爱好者周刊（第 417 期）：不要让 AI 代表你¶

    工具¶

    1、Everything

    这个 Everything 项目致力于将全世界所有常用软件都用 AI 重写一遍，目前已经完成了几十种。

    这些软件本身或许没什么亮点，但是这个项目的目标实在太惊人，难以想象如果实现了，会是怎样的结果。

    2、TitleArt

    这个 Web 应用将上个世纪的美术字编辑器，搬到了浏览器。

    3、Overgrown

    这个浏览器插件会让闲置的网页长满藤蔓，再次浏览页面的时候，需要用鼠标砍断藤蔓，参见介绍文章。

    4、make-look-scanned

    一个命令行工具，让 PDF 文件看起来像是通过纸张扫描生成的（上图）。

    5、What's Up Docker

    本地的容器管理应用，带有 Web 界面。

    6、OpenIDEA

    一个开源的桌面 IDE，保留 IntelliJ IDEA 的使用习惯，底层用 Rust + Tauri 2 重写。（@l0ng-ai 投稿）

    7、Oleafly

    开源的科研写作编辑器，支持 LaTeX、Typst 和 Markdown，不用单独安装 TeX 发行版。（@prajwal-svm 投稿）

    8、Weblink

    开源的 Windows 远程桌面工具，通过浏览器共享远程桌面，并可远程控制鼠标和键盘，支持文件传输、剪贴板共享、聊天及语音视频通话。（@99percentpeople 投稿）

    9、MenuBarMijia

    在 Mac 菜单栏与 Win11 托盘里控制米家和 Home Assistant 设备。（@jryang1997 投稿）

    10、无名大叔系统优化工具箱（3z9wOpt）

    开源的 Windows 系统优化工具箱，包括清理垃圾、管理启动项与驱动等功能，技术栈是 Go + Wails v2 的桌面程序。（@3z9w 投稿）

    11、Cloud Mail

    基于 Cloudflare 的一站式邮箱服务平台。只需要一个域名，就可以搭建自己的邮箱服务，可部署到 Cloudflare Workers。（@aslost 投稿）

    12、晒窗 ShaiWin

    把 Windows 窗口挂到屏幕顶端的一根晾衣绳上，点击后复原。（@19y 投稿）

    13、openhongguo

    红果短剧（Hongguo）的非官方匿名 SDK，提供 Go、Node.js、Android、iOS、React Native 和 Flutter 版本。（@beilunyang 投稿）

    14、FoldGit

    约 4 MB 的轻量级原生 macOS Git 客户端，集中管理多个仓库与工作树。（@dufu1991 投稿）

    资源¶

    1、墨观 inkstone

    代码编辑器的配色方案，共有六个变体，从 526 个中国传统颜色中提取。（@Konata9 投稿）

    2、《追忆似水年华》全七卷 AI 译本

    这个仓库是文学巨著《追忆似水年华》的 AI 翻译。（@QriDoki 投稿）

    3、吉卜力搜索

    这个网站可以语意搜索吉卜力工作室的电影画面。
