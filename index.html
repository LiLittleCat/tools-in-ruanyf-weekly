    阮一峰老师科技爱好者周刊汇总¶

    前言¶

    很喜欢阮一峰老师的 科技爱好者周刊，尤其是「工具」和「资源」部分内容，非常有趣且实用。

    但是到目前为止周刊已经太多期，苦于查找困难，特将其汇总于此，方便查阅。

    新版站点（推荐）¶

    在线访问：https://ruanyf-weekly.yl.do

    基于 Fumadocs（Astro）重新搭建的栏目汇总站，代码在 fumadocs 分支：

    • 栏目汇总：话题、科技动态、文章、教程、工具、资源、AI 相关、图片、文摘、言论 —— 每个栏目把所有期数的内容集中在一起，按年份分册浏览
    • 期刊归档：每一期的完整原文，按年份归类
    • 全文搜索：支持中文，覆盖所有期数的正文
    • 每周五自动同步最新一期，由 Cloudflare Pages 构建发布

    科技爱好者周刊（第 419 期）：机房来了，写字楼走了¶

    工具¶

    1、Window Sweaters for macOS

    一个 Mac 应用，为常见应用的窗口穿上毛衣。

    2、dnsglobe

    一个命令行工具，对全球34个公共 DNS 进行测速，找出到你速度最快的 DNS 服务器。

    3、kan.ban

    基于 JS 的开源看板应用，Trello 替代品。

    4、Procexp-Mac

    一个 macOS 桌面应用，可以查看每个进程的详细信息，相当于把 Process Explorer 移植到 Mac。

    5、rVPN

    一种开源的加密通信协议，可以让加密通信与 HTTPS 无法区分，提供服务端与各种客户端。

    6、BoopFace

    一个 Web 组件，可以在网页插入 SVG 机器人脸组件，适用于 AI 聊天机器人和 Agent 界面，提供18种表情和互动。（@CX-ArtLab 投稿）

    7、Melarka

    一个本地的音乐流媒体服务器，可以播放本地和 YouTube 音乐，支持多账号，提供安卓和 iOS 客户端。（@aaronsuns 投稿）

    8、Cyber API

    用于 API 调试的桌面客户端，使用 Rust + GPUI 构建，由于通过 GPU 直接绘制，没有了 Electron 的内存占用与卡顿。（@vicanso 投稿）

    9、Beamlynx

    一个桌面的数据库客户端，在数据库里删一行数据，它会找出所有指向这行数据的表，删除时不会留下指向已删除行的外键，非商业使用免费。（@ahmadnazir 投稿）

    10、MD-Vault

    一个 Web 应用，使用 Markdown 格式保存 2FA 双因素认证的动态时间码，通过网页看板查看。（@xiangc579 投稿）

    11、zlib

    Z-Library 的命令行客户端，可以搜索、下载图书。（@heartleo 投稿）

    资源¶

    1、temp-api

    这个网站提供免费的 JSON API 的 Mock 服务。（@sunjian-github 投稿）

    2、MCP 详解

    这个网站提供 MCP 教程，把相关概念都用图形解释。看上去是用 AI 生成的，但对于了解 MCP 还是有帮助。

    3、Rail Cube

    这个网站演示使用类似于乐高积木的火车积木 Rail Cube，可以搭建的约2700万个轨道布局。

    4、Hacker News 未公开的特性

    这个仓库收集 Hacker News 网站没有公开的各种特性和功能。
