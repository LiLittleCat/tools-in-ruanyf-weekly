    阮一峰老师科技爱好者周刊汇总¶

    前言¶

    很喜欢阮一峰老师的 科技爱好者周刊，尤其是「工具」和「资源」部分内容，非常有趣且实用。

    但是到目前为止周刊已经太多期，苦于查找困难，特将其汇总于此，方便查阅。

    新版站点（推荐）¶

    在线访问：https://ruanyf-weekly.yl.do

    基于 Fumadocs（Astro）重新搭建的栏目汇总站，代码在 fumadocs 分支：

    • 栏目汇总：话题、科技动态、文章、教程、工具、资源、AI 相关、图片、文摘、言论 —— 每个栏目把所有期数的内容集中在一起，按年份分册浏览
    • 期刊归档：每一期的完整原文，按年份归类
    • 全文搜索：支持中文，覆盖所有期数的正文
    • 每周五自动同步最新一期，由 Cloudflare Pages 构建发布

    科技爱好者周刊（第 418 期）：如果科技停止在21世纪初¶

    工具¶

    1、florilegium

    LaTex 排版软件的插件，在页面空白处生成植物图案。

    这个概念很棒，而且可以移植到网页。

    2、Disc Image Studio

    这个工具可以将指定的图片刻录到光碟上，使得图案在光碟表面上肉眼可见。

    3、OutCrap

    一个免费的手机 App（苹果和安卓），可以根据照片分析地质地貌，也可以根据 GPS 定位给出地质信息。

    4、SOML

    一种可以取代 JSON 的数据文件格式，消除了 JSON 的大多数缺点，更容易使用，基本上是 YAML 的简化版，提供各种语言的实现。

    5、Casnode

    开源的 Discourse 风格的论坛程序，采用 Go + Next.js 开发，数据库默认为 SQLite。（@hsluoyz 投稿）

    6、澜姿

    这个开源工具提供一套可以微调的人体姿态/服装/表情模板，供 AI 模型套用到图片上面。（@zc520pyfm 投稿）

    7、Crossbow

    开源的代理桌面客户端，支持双内核一键切换。（@Richard-Zhang1019 投稿）

    8、WeRead Book Exporter

    微信读书全书无损导出工具，抓取微信读书 Web 端已购或会员书籍全文，一键导出为 PDF、EPUB 以及 Markdown 笔记。（@WANGXIN-567 投稿）

    9、Linkit

    浏览器书签的桌面管理器，基于 Go + Wails + SQLite 构建，支持本地语义向量检索、404 死链检测与知识图谱。（@blue-idea 投稿）

    10、halfsize

    开源的命令行工具，将视频文件压缩到指定大小。（@YKLovePython 投稿）

    资源¶

    1、HackerTube

    一个 Youtube 视频网站，汇集了“黑客新闻”论坛上提到的所有 Youtube 视频，可以用来寻找值得看的科技视频。

    另有 HackerBooks 和 HackerPodcasts，分别收集了“黑客新闻”提到过的各种书籍和播客。（@qcrao 投稿）

    2、开始学习图论（Start Doing Graph Theory）

    一本面向初学者的图论入门教材（英文），免费阅读和下载。

    3、Python 数据科学手册（英文）

    该书向初学者介绍用于数据处理的一些 Python 基本工具（比如 NumPy、Pandas），出版于2016年，免费阅读。
